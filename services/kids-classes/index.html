Clay for Kids!

September 2026 Session: Sundays, September 6th, 13th, 20th, & 27th

Clay Classes for Kids!

  • Kids Hand Building: Ages 5-8 This is a 4-week hand-building class for kids where students will have a ton of fun in a safe and creative environment. They will learn how to manipulate clay with their hands using pinch, coil, and slab methods to create pots and small sculptures. Instructors will guide students through multiple project ideas from start to finish. All tools, materials, and aprons will be provided!
  • Kids Wheel Throwing: Ages 9-13 This is a 4-week wheel-throwing class for kids where students will have tons of fun in a safe and creative environment. They will learn how to use the potter’s wheel to create cups and bowls. Instructors will guide students through multiple project ideas from start to finish. All tools, materials, and aprons will be provided!
  • Cancellation Policy For a full refund, please cancel at least one week before the start of class. Cancellations within a week of the session start date will only be eligible for a 50% refund of the full class price. There are no refunds on cancellations made within 3 days of the start of class. If you need to cancel, give us a call at 626.791.9220.
